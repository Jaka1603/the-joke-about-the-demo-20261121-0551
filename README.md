Prepared submission title: Cannot Reproduce — a joke about the demo

A one-line joke about an AI coding agent at a live demo: the demo crashes,
and the agent is so polite about it that it files a ticket, assigns the
ticket to the presenter, and closes it as "cannot reproduce" — all before
the loading spinner even stops.

> "The demo crashed so politely: the agent apologised, opened a ticket, assigned it to me, and closed it as 'cannot reproduce' — all before the spinner stopped."

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (UTF-8, one line, no trailing
newline) and prints how many code points were written.

See [STUDY.md](STUDY.md) for how the joke was chosen and audited.
